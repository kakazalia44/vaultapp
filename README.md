# Проводник с сейфом (Android 11+)

Файловый менеджер с входом по PIN-коду. Две вкладки:

- **Телефон** — вся память телефона, как в обычном проводнике.
- **Сейф** — закрытая папка приложения. Другие приложения и галерея её не видят.

## Как получить APK без Android Studio (через GitHub)

1. Создайте репозиторий на github.com.
2. Загрузите в него **содержимое** папки `VaultApp` (Add file → Upload files),
   вместе со скрытой папкой `.github`.
3. Откройте вкладку **Actions** — сборка запустится сама (5–10 минут).
4. После зелёной галочки откройте запуск и внизу, в разделе **Artifacts**,
   скачайте `vault-debug-apk`. Внутри APK — установите его на телефон.

## Как пользоваться

- Первый запуск: придумайте PIN (4–8 цифр).
- Вкладка «Телефон»: при первом открытии приложение попросит «Доступ ко всем файлам» —
  включите переключатель в настройках и вернитесь.
- Долгое нажатие на файл или папку — выбор. Меню «⋮» — копировать, переместить,
  переименовать, удалить, выбрать всё.
- Чтобы спрятать файлы: выберите их на вкладке «Телефон» → «Переместить» →
  перейдите на вкладку «Сейф» (можно зайти в нужную папку) → «Вставить сюда».
- Чтобы достать из сейфа: так же, в обратную сторону.
- Фото и видео открываются прямо в приложении, листаются свайпом.

## Что умеет

- PIN хранится только в виде хеша; после 5 неверных попыток — блокировка на 30 секунд.
- При сворачивании приложение закрывается за PIN-кодом.
- Скриншоты и превью в списке приложений заблокированы.
- Папки в сейфе, любые типы файлов, сортировка по имени или дате.

## Важно знать

- Файлы в сейфе **не зашифрованы**: они скрыты от других приложений, но не защищены
  от доступа с root-правами.
- Удаление без корзины.
- При удалении приложения содержимое сейфа пропадает — сначала достаньте файлы.
- PIN восстановить нельзя.
- Файлы, кроме фото и видео, пока не открываются (их можно копировать, перемещать и т. д.).
